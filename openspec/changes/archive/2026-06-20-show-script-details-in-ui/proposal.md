# Change: UI 展示脚本详情预览

## Why

本地 UI 目前只展示脚本名称。用户选择一个脚本后，需要回到代码里看它会点击什么、等待什么、依赖哪些图片或界面状态。随着 `ScreenStateIs(...)`、图片别名、点位别名和状态探测能力增加，脚本的可理解性会变成使用门槛。

这一步让 UI 在运行前展示脚本摘要，让用户能快速判断脚本是否依赖当前状态、图片资源和具体动作。

## What Changes

- application 层新增脚本详情用例，返回脚本名称、步骤摘要和依赖摘要。
- HTTP 增加按脚本名读取详情的 endpoint。
- UI 在脚本选择变化时加载并展示脚本详情。

## Impact

- 修改能力：`local-control-ui`
- 不新增脚本编辑能力，不改变脚本执行语义，不改变领域模型字段。
- 详情摘要是面向用户的诊断信息，不作为脚本执行输入。
