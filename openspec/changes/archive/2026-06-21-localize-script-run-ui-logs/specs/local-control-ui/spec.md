## MODIFIED Requirements

### Requirement: UI 展示运行日志和图片匹配耗时

本地控制 UI SHALL 展示后台脚本运行期间产生的日志，包括普通输出、错误输出、步骤事件和图片匹配耗时诊断。后台状态 payload MUST 保留 stdout/stderr 文本日志，并 MAY 同时暴露结构化事件列表供 UI 后续分组展示。脚本控制页停止按钮下方的输出框 MUST 使用中文展示运行过程日志；当 payload 包含结构化事件时，UI MUST 优先用事件生成中文日志，并避免重复展示兼容文本中的英文事件行。

#### Scenario: 展示图片匹配日志

- **WHEN** 脚本执行图片存在判断或图片目标点击
- **THEN** UI 日志包含该次图片匹配的模板路径、耗时毫秒、是否命中和置信度摘要

#### Scenario: 展示步骤事件日志

- **WHEN** 脚本执行点击、等待、Repeat、If 或 WaitUntil
- **THEN** UI 日志包含对应步骤的开始、成功或失败事件
- **AND** 事件日志使用中文展示

#### Scenario: 日志随状态轮询更新

- **WHEN** 后台脚本仍在运行且产生新日志
- **THEN** 页面下一次状态轮询展示追加后的日志内容
- **AND** 日志框滚动到最新内容
