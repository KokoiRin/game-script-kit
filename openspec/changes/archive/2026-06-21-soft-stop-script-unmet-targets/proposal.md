## Why

真实游戏脚本里，按钮、图片或界面状态暂时没出现是常见情况。当前脚本会把图片目标未找到、`WaitUntil` 超时直接视为运行失败，UI 也把每次轮询都展示成一行日志，导致用户很难判断脚本是否正常结束。

## What Changes

- `WaitUntil` 条件超时后正常停止本轮脚本，不执行后续步骤，不再按失败退出。
- `Click(ImageTarget(...))` 未定位到图片目标时正常停止本轮脚本，不执行点击和后续步骤。
- 配置错误、未知别名、缺少运行端口、取消运行仍保持现有错误/取消语义。
- UI 运行日志收敛为关键中文事件，不展示每次条件轮询和普通步骤成功噪音。

## Impact

- 更新 `game-script-core` 执行语义。
- 更新本地控制 UI 日志展示要求。
- 调整 runner、application 和 UI 测试。
