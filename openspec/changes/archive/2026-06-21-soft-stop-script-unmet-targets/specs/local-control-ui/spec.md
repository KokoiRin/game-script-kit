## MODIFIED Requirements

### Requirement: UI 展示运行日志和图片匹配耗时

本地控制 UI SHALL 在脚本控制页的黑色运行输出框中使用中文展示脚本运行日志。日志 SHOULD 优先展示关键运行事件，包括脚本开始、等待条件满足或超时停止、图片目标定位成功或未找到停止、实际点击、等待动作、脚本结束和错误。UI MUST NOT 默认逐条展示 `WaitUntil` 的每次轮询判断，也 MUST NOT 把结构化事件重复展示为英文文本日志。

#### Scenario: 日志随状态轮询更新

- **WHEN** 后台脚本仍在运行并产生新的运行事件
- **THEN** UI 的黑色运行输出框会展示精简中文日志
- **AND** 日志框滚动到最新内容
