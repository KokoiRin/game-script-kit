# Change: 使用探测状态填充 dry-run 模拟状态

## Why

本地 UI 已经能循环探测当前界面状态，也能在 dry-run 运行脚本时手动输入模拟状态。现在这两个能力仍是分开的：用户看到“当前状态：主页”后，还需要手动把 `主页` 输入到脚本控制区，才能验证 `ScreenStateIs("主页")` 分支。

这一步把探测结果接到 dry-run 输入上，让用户可以用当前识别到的状态快速调试状态驱动脚本。

## What Changes

- 在脚本控制区的模拟状态输入旁增加“使用探测状态”按钮。
- 前端保存最近一次界面探测状态；用户点击按钮时，把非 `未知` 的探测状态写入模拟状态输入。
- 如果没有可用探测状态，按钮不覆盖用户当前输入，并给出页面状态提示。

## Impact

- 修改能力：`local-control-ui`
- 不新增后端 endpoint，不改变 `ScreenStateIs`、状态探测、脚本执行或配置文件语义。
- 只影响本地 UI 的 dry-run 调试体验。
