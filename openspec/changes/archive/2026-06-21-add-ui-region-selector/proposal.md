## Why

编写脚本时，区域坐标经常需要在截图、鼠标工具和 JSON 之间来回换算。不同工具使用的坐标系可能不一致，导致状态识别和图片搜索区域容易写错。用户已经可以在 UI 中截屏，因此最直接的改进是在这张截图上拖拽选择范围，并把可用于脚本配置的区域坐标直接展示出来。

## What Changes

- 在本地控制 UI 的截图预览上支持拖拽选择区域。
- UI 根据截图像素尺寸和真实屏幕坐标尺寸换算出脚本可用的 `left/top/width/height`。
- UI 展示可直接复制到 JSON 的区域片段。
- 用户选中区域后，可以用当前选择的素材和最低置信度执行一次区域内图片匹配预览。
- 匹配预览返回是否命中、置信度、匹配矩形和日志摘要，不执行点击。

## Impact

- 新增一个本地 UI HTTP endpoint 用于图片区域匹配预览。
- 扩展截图接口 payload，带回截图像素尺寸和屏幕坐标尺寸。
- 扩展 `ScreenDiagnosticsUseCase`，复用现有图像定位端口执行只读匹配。
