## Why

脚本详情已经能展示状态分支摘要，但用户仍需要自己把“当前识别到的界面状态”和“脚本会走哪个分支”对应起来。把这个判断直接展示在 UI 中，可以降低调试状态驱动脚本时的理解成本。

## What Changes

- 在脚本详情的状态决策摘要中，根据最近一次界面探测状态展示当前会走“命中”、“未命中”或“未知”。
- 当后台界面探测更新当前状态时，已展示的脚本详情会同步刷新该预览。
- 不改变脚本执行语义、不改变脚本详情 HTTP payload、不新增后端接口。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `local-control-ui`: 脚本详情中的状态决策摘要会结合最近探测状态展示当前分支预览。

## Impact

- 影响本地控制 UI 静态前端逻辑和对应静态资源测试。
- 不影响核心脚本模型、执行引擎、平台 adapter 或 HTTP payload schema。
