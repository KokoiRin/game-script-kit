## ADDED Requirements

### Requirement: 批量图片定位支持独立搜索请求
系统 SHALL 支持在同一轮批量图片定位中接收一组搜索请求。每个搜索请求 MUST 包含模板图片、可选搜索区域和最低置信度。真实桌面 adapter MUST 在一轮请求中只截取一次屏幕，并按每个请求自己的搜索区域执行模板匹配。

#### Scenario: 每个请求使用自己的区域
- **WHEN** 批量定位请求包含 `离开.png` 使用 `右上弹窗` 区域，以及 `重来.png` 使用 `底部按钮栏` 区域
- **THEN** adapter 在同一张截图上分别裁剪对应区域执行匹配
- **AND** 返回结果按请求顺序对应每个搜索请求

#### Scenario: 请求级最低置信度
- **WHEN** 批量定位请求中不同图片使用不同最低置信度
- **THEN** adapter 按每个请求自己的最低置信度判断是否命中

#### Scenario: 独立搜索请求支持命中即停
- **WHEN** 批量定位按搜索请求顺序启用命中即停
- **AND** 第一个请求已命中
- **THEN** adapter 不再匹配后续请求，并把后续请求结果标记为 skipped
