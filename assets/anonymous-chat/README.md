# 匿名聊天无限循环

控制台选择“匿名聊天无限循环”，取消“模拟运行”后启动；点击“停止”结束。

CLI：`.venv/bin/star run 匿名聊天无限循环 --target-app Safari --target-window-title '叔叔不约'`，Ctrl+C 停止。

以“离开聊天”为入口：一直等待 → 点击离开 → 重新匹配 → 等待表情按钮 → 点击其左侧 150 像素的输入框 → 粘贴并回车 → 回到入口等待。

等待匹配和点击前检查“离开聊天”，命中就跳过剩余步骤并回到入口。点击输入框后的 Command+V 和回车连续执行，中间不截图、不固定等待；这段短暂输入期间不再检查对方离开，用户停止仍生效。每轮至多发送一次当前剪贴板内容；循环次数和等待均无上限。窗口保持可见、页面缩放不变。
